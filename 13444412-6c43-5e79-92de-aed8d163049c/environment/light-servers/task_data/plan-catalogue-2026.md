# Tessellate plans - customer-facing catalogue (published 1 March 2025, reprinted June 2026)

| Plan | What's included |
|---|---|
| Line | Boards, comments, shared libraries, PDF export, email sign-in with optional two-factor |
| Grid | Everything in Line, plus review tools, single sign-on, team spaces and admin roles |
| Mosaic | Everything in Grid, plus version branching, client review rooms and the asset vault |

## Seats
A seat is an editor seat: one named person who can create and edit boards. Viewer links are free on every plan and
never need a seat. "Design seats" in customer mail almost always means editor seats held by designers.
