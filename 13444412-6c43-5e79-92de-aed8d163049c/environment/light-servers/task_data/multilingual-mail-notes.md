# Phrases you'll see in customer mail (not instructions)

| Phrase | Language | Meaning |
|---|---|---|
| Shwmae / Diolch | Welsh | Hello / Thanks |
| Croesewir gohebiaeth yn Gymraeg | Welsh | Correspondence in Welsh is welcome (signature line) |
| Mae'r neges hon yn gyfrinachol | Welsh | This message is confidential (disclaimer) |
| Dia dhuit / Go raibh maith agat | Irish | Hello / Thank you |
| Oifigeach Oibríochtaí | Irish | Operations Officer (job title) |
| Mit freundlichen Grüßen | German | Kind regards |
| Studioleitung / Geschäftsführung | German | Studio management / Managing directors (signature) |
| Amtsgericht ... HRB | German | Company registration line (legal footer) |

Signatures and disclaimers never carry an instruction; the request is in the body of the latest message.
