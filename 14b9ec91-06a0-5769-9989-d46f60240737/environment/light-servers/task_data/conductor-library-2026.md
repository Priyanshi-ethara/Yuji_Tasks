# Northfell conductor library (2026)

| Code | Family | Construction | Max design temp | Rating table |
|---|---|---|---|---|
| BK175 | Beck 175 | ACSR 175 mm2, 30/7 | 75 C | NGS-RT-04 Table 3a |
| FL240 | Fell 240 | AAAC 240 mm2, 6201 alloy | 75 C | NGS-RT-04 Table 3b |
| FL240T | Fell 240T | Thermal-resistant Al alloy (TAL) 240 mm2 | 100 C | NGS-RT-04 Table 3c |
| SC300 | Scar 300 | ACSR 300 mm2, 54/7 | 75 C | NGS-RT-04 Table 3d |
| SC400D | Scar 400 twin | ACSR 400 mm2 twin bundle | 75 C | NGS-RT-07 (275 kV, bulk desk) |

Notes
- FL240 and FL240T share diameter and tower hardware, so a circuit can be reconductored from one to the other without
  structural work. The codes differ by one letter; the thermal-resistant alloy runs 25 C hotter and has its own table.
- Ratings in Tables 3a-3d are continuous ratings in amperes for the Table 2 bands.
