# MET-SOP-009 Returned-logger as-found checks

Revision 6, Metrology, effective 1 October 2026.

1. Any logger whose export carries a self-check flag, and one in ten others at random, is returned to Metrology after
   the shipment.
2. Metrology performs an as-found check before any adjustment and issues a calibration certificate to the Box folder
   "Logger calibration certificates 2026". The certificate is the only record that declares a sensor-fault window.
3. A sensor-fault window is declared only when the as-found check reproduces a measurement fault and the logger's
   diagnostic trace dates it. A self-check flag with a passing as-found check is not a sensor fault.
4. Certificates are identified by the logger id. Logger ids are reused across lanes only after retirement; check the
   id character by character, BL-3320 and BL-3230 are different loggers.
