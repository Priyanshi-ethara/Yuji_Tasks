# Nordmark Notified Body 2291 - technical file submission checklist (client edition 2026)

1. Table of contents covering every section of the manufacturer's ToC standard, each with the document number and
   revision in force, page count and a completeness statement.
2. An index of defined terms used in the file.
3. A list of open gaps with the manufacturer's closure plan. Files with open gaps are accepted for a completeness
   check but not for technical review of the affected sections.
4. A summary of safety and performance for class C and class D devices.
5. Upload: by the manufacturer's designated submitter only, through the client upload area. Each upload is a formal
   submission and starts the review clock; uploads cannot be withdrawn.
6. Revisions released after upload are submitted as a change notification, not by replacing files.
