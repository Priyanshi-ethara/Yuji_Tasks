# FAQ — tracker current
Q: Which current do we compare? A: The inverter's maximum short-circuit input current per MPPT tracker (catalogue), against p × Isc × 1.25.
Q: Do we add bifacial gain? A: No (Corvane note, October 2026).
Q: Do we temperature-correct Isc? A: No. Clause 6 uses the STC Isc.
Q: Does an overcurrent return change the string length? A: Not by itself; clause 8 looks only at clauses 4 and 5.
