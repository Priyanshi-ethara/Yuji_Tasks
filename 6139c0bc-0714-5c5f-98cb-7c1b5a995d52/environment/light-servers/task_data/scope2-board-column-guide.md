# Inventory board — column guide (monday.com, board "FY2026 Scope 2 inventory")

The board has one item per site, created by the desk lead from the site register. Facilities columns (Site code, EFS
region, Review status) are maintained by the desk lead. The analyst fills three columns per item:

| Column (title on the board) | Column id | Content |
|---|---|---|
| Location-based tCO2e | loc_tco2e | number, one decimal, no thousands separator |
| Market-based tCO2e | mkt_tco2e | number, one decimal, no thousands separator |
| Instrument applied | instrument_applied | as the protocol in force §8 prescribes |

The FY2025 board in the same workspace is closed and kept for comparison; never edit it.
