# fleetd 4.12 release notes

## 4.12.1 — 13 Nov 2026
- dispatch: lease renewer re-arms per lease instead of per tick (Fleet Reliability). Known issue: re-arm after Stop
  can still panic during shutdown; fix in #3471.
- billing: quote page explains the last carrier decline (Billing & Settlement).
- ingest: heartbeat interval 2s.
- build: Go 1.23.3; `-mod=vendor -trimpath`. Vendored dependency set unchanged from 4.12.0.

## 4.12.0 — 10 Nov 2026
- telemetry: exporter batch size configurable, production 512 (Platform Foundations).
- notify: digest scheduler moved onto the simkit timing wheel (Messaging).
- geo: ETA estimator reads the simulation clock so simctl replays give stable ETAs (Maps & Routing).
- billing: settlement queue flushes each item on a scheduler callback (owned by Messaging since #3415).
- api: RouteRequest validation generated by protoc-gen-validate (API Contracts).
